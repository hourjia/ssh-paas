## 1. 产品定位

一个 **本地 App + SSH 操作服务器** 的部署管理工具（不使用 Dokploy / Coolify 那类"服务器驻留面板"）。

核心理念：

| 理念 | 说明 |
| --- | --- |
| **手动部署** | push 只发布，上线必须人工确认（版本安全） |
| **服务器零侵入** | 服务器上不装任何管理面板，只有应用、Traefik 和共享服务 |
| **服务器为唯一真源** | 本地 App 只是可丢弃的视图缓存，换电脑零迁移 |
| **版本可控** | 每次部署绑定不可变版本（Git Tag），可审计、可秒级回滚 |

## 2. 总体架构

### 本地 App（你开发的部分）

```text
本地 App（你开发的部分）
├─ 服务器管理：SSH 连接档案、初始化、探测
├─ 构建：本地构建镜像（自动匹配服务器 CPU 架构）
├─ 发布：组装交付包 → push 到 example_build 仓库
├─ 部署编排：SSH 下发命令、实时日志流、健康检查
├─ 版本台账 + 回滚、应用清单 + 对账状态
└─ 可视化：部署时间线、日志、证书状态、多服务器总览
```

### 服务器（每台）

```text
服务器（每台）
├─ Traefik（唯一的常驻管理组件）：HTTPS 自动签发/续期、子域名路由
├─ registry:2（可选，127.0.0.1）：镜像分发，SSH 隧道推送
├─ /srv/apps/<app>/        ← 交付仓库的 checkout（每个应用）
└─ shared-net：postgres / redis 等共享服务（不暴露公网）
```

## 3. 核心链路：四步流水线

```text
Git 源仓库 ──► 本地构建 ──► 发布交付包 ──► SSH 部署 ──► 服务访问
   选 Tag       buildx        push 到        checkout      https://
               按服务器      example_build   版本 + compose app-a.example.com
               架构构建      打 Tag          up + 健康检查
```

关键决策：

| 环节 | 决策 | 理由 |
| --- | --- | --- |
| 部署触发 | 手动（App 里选 Tag → 部署） | 上线是人的决策，安全可控 |
| 构建位置 | 本地构建 + 自动注入 `--platform` | 服务器零构建负担，构建快 |
| 交付方式 | Git 交付仓库（`example_build`） | 发布与上线解耦，Tag 即台账，回滚即 checkout 旧 Tag |
| 交付内容 | `dist` + 薄 Dockerfile + compose + `release.json` | Git 里放产物不放镜像，服务器秒级 build |
| 运行载体 | Docker + compose（默认） | 一个文件管全部，共享服务好管理，迁移零成本 |
| 域名绑定 | 子域名（`app.example.com`），一条泛解析 `*.example.com` | 无 DNS API 集成，应用跑根路径零适配 |
| HTTPS | Traefik + Let's Encrypt HTTP-01，逐子域名自动签发/续期 | 新服务上线即出证书，全程无人工 |
| 公用服务 | 独立于应用生命周期，挂 `shared-net`，连接串由平台注入 | 回滚应用不影响数据，升级数据库与部署解耦 |

## 4. 交付契约

`example_build` 标准结构：

```text
example_build/
├── dist/                # 构建产物
├── Dockerfile           # 薄封装：FROM 共享基础镜像 + COPY dist/
├── docker-compose.yml   # Traefik label、shared-net、健康检查、deploy.* 标签
├── release.json         # { app, version, source_commit, built_at, requires }
└── .env.example         # 环境变量名清单（值永不进 Git）
```

三个固定约定：

1. **基础镜像 tag 锁定统一版本**（如 `node:22.11-alpine`），层共享 → 运行时磁盘只存一份；
2. **容器打 `deploy.*` label**（app/version/repo/domain/health）→ 运行态可对账；
3. **真实密钥通过 SSH 落服务器 `env/` 目录**（gitignore），compose 用 `env_file` 引用。

Docker 网络模型：

| 网络 | 连接对象 | 说明 |
| --- | --- | --- |
| `proxy-net` | Traefik ↔ 各应用容器 | 仅带 label 的才被路由 |
| `shared-net` | 应用 ↔ 数据库等 | 数据库不接 `proxy-net`，不暴露公网 |

## 5. 服务器初始化（一次性，幂等）

1. **探测**：架构 / OS / 内存 / 80、443 端口占用（生成服务器档案）；
2. **基础**：git、curl、ufw，时区 + NTP，小内存加 swap；
3. **Docker**：通过 get.docker.com 安装 Engine + Compose 插件；
4. **骨架**：创建 `/srv/apps`、`/srv/shared`、`/srv/traefik`、`/srv/data`，以及 `proxy-net` / `shared-net`；
5. **Traefik**：compose 常驻，`exposedbydefault=false`，ACME 自动签发，80 → 443 跳转，`acme.json` 权限 `600`；
6. **防火墙**：ufw 放行 22 / 80 / 443；
7. **共享服务**：按需安装（第一个依赖它的应用部署时再装 postgres 等）。

> **原则**：探测先行、幂等执行（已做则跳过），结果写入服务器档案。

**重复执行的约定**：服务器上已存在 `/srv/.ourjia/init.json` 台账时，初始化入口默认不再执行任何步骤，只做只读状态采集（不会重装 Docker、不会重新拉取 Traefik 镜像、不会重写 daemon.json）。配置变更需要显式「应用配置变更」：平台按台账配置 + 服务器实际状态算出受影响步骤，只执行这些步骤并更新台账；「强制重新初始化」才会完整跑一遍全部步骤，仅在环境被破坏时使用。

## 6. 状态模型：发现与对账

三层信息，全在服务器上，无需登记中心：

| 层 | 来源 | 回答 |
| --- | --- | --- |
| **声明态** | `/srv/apps/*/release.json` + `git describe` | 声明部署了什么版本 |
| **期望态** | compose 项目（`docker compose ls`） | 应该跑什么 |
| **运行态** | 容器 + `deploy.*` label + 健康检查 | 实际跑着什么 |

**同步流程**：

> 连接 → 探测初始化状态（已初始化则跳过）→ 全量扫描三层 → 对账生成"服务器快照" → 刷新 UI。
>
> 本地快照可随时丢弃重建，换机器即重连即恢复。

**配置备份与恢复**：应用配置（含环境变量）可导出为 JSON 文件（`GET /api/apps/export`，仅本机），`server/data/apps.json` 丢失或换机器时再用导入恢复（`POST /api/apps/import`，先 dry-run 逐条预览）。文件只带服务器身份（host + port + user）不带 SSH 凭据，导入时按身份匹配已添加的服务器，只新增应用、同 ID 跳过，环境变量导入后重新加密落库。服务器上的 `release.json` 只记录环境变量名，不记录值，因此不拿它反向还原配置。

**对账状态机**：`running` / `unhealthy` / `stopped` / `orphan` / 有新版本 —— 清单自带体检，异常项直接给出操作入口（看日志 / 启动 / 接管清理 / 部署新版）。

## 7. 项目设置项（每应用可配）

- **运行时载体**：Docker（默认）/ systemd（极端受限环境降级选项）；
- **交付通道**：Git 交付（默认）/ 镜像交付（重依赖项目用 registry 隧道 push）；
- **域名**：默认 `项目名.example.com`，部署前 DNS 解析校验；
- **资源与健康**：资源限制、健康检查路径、共享服务勾选（自动注入连接串）。

## 8. 安全基线

- 服务器只持有 `example_build` 的只读 deploy key；源码凭据、DNS 账号永不落服务器；
- 本地构建，服务器不存源码、不扛构建；
- Traefik 仅暴露 80 / 443，应用容器零宿主机端口；未匹配 Host 统一返回 404（防泛解析搭便车）；
- 部署锁防并发，每次部署留台账（版本、时间、源 commit）；发布后自动 / 一键回滚。
